  and is the only current cohort whose parallel Drove cells beat the C1

  slower than their C1 reference runs in this single sample.
- Container peak memory is higher for every Drove cell and rises with lane
  count. The data does not prove copy-on-write memory savings.

No PRD speed threshold was applied. Repeated controlled runs and the canonical
cheap/setup-dominated fixtures are still required before claiming performance.
